# Campus Resource Reservation System

GitHub: https://github.com/asangarimal-lab/Campus-Resource-Reservation-System

Group project. We are building a small program so students can reserve
campus resources (rooms, laptops, lab kits, tutoring times).

## Team

- Asanga Rimal — reservations + linked list (`asanga-rimal`)
- Sebastian Balderrama — resource management
- Anugrah Lama — waiting list queue and cancellation stack

## Branching (please follow this)

We are not committing straight to `main`.

1. Each person works on their own branch. Asanga's branch is
   `asanga-rimal`. Other members should use a branch with their name
   the same way.
2. When a milestone is done, we merge those branches into a milestone
   branch (`milestone-1`, then later `milestone-2`, ...).
3. After we compile and test that milestone, we merge it into `main`.

```
person branches  ->  milestone-N  ->  main
```

Milestone 1 code lives on `milestone-1` until we merge it.

Checkout:

```
git clone https://github.com/asangarimal-lab/Campus-Resource-Reservation-System.git
git checkout milestone-1
```
